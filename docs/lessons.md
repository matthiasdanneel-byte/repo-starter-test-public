# Lessons this repository has learned

Every entry is something that actually went wrong while building this project, written so it
doesn't happen twice. Claude adds an entry in the same pull request as the fix. A lesson that
comes back a second time is promoted to a one-line rule in `CLAUDE.md`, and the entry says so.

## Entry format

```
## YYYY-MM-DD: <short title>

**What went wrong.** One or two sentences: what happened, and what it cost.
**Why.** The cause, not the symptom.
**The rule.** What we do from now on, and the check that catches it.
```

Newest entries go at the bottom.
